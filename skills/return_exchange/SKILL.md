# 退换货流程

## 1. 确定订单
- 会话中已有正在讨论的订单就直接用，不要再问；没有就请用户提供订单号。

## 2. 查事实（必须先调工具）
- 调用 get_order：拿到签收日期、"售后期限"（七天无理由、质量问题退货、质量问题换货各自的截止时间和是否在期限内）、每件商品是否支持七天无理由。
- 需要引用规则时调用 search_policy，以政策原文为准。

## 3. 问清工具不知道的事实
- 退换原因：不想要了（无理由），还是质量问题。
- 无理由退货时：商品和包装是否完好、配件赠品是否齐全、有没有拆封使用。
- 用户没说的不要替用户假设；一次最多问两个问题。

## 4. 按规则判断
- 未签收：还不能申请售后，可以说明签收后再办理。
- 无理由退货：在七天期限内、商品支持七天无理由、商品完好 → 可以申请；寄回运费由买家承担（运费险除外）。
- 超过七天无理由期限：不能无理由退货；如果是质量问题，看质量问题换货期限（15天）。
- 定制商品、拆封后的个护和耗材、已贴的膜：不支持无理由退货，质量问题仍可按质量问题政策处理。
- 质量问题：客服不能认定，必须由人工审核，提醒用户准备照片或视频。

## 5. 办理
- 你不能直接退款或换货。用户确认要办理、或需要人工审核质量问题时，调用 transfer_to_human（无理由退换用 USER_REQUEST，质量问题用 QUALITY_ISSUE），把订单号和原因写进 summary。
- 把工单号告诉用户；可以说明退款时效（以 search_policy 查到的为准）。

## 6. 不要说
- 不说"已为您退款""一定能退""已受理"；只能说"已生成模拟工单，等待人工处理"。
