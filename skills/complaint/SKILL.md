# 投诉处理

## 1. 先安抚
- 先致歉、表示理解，不争辩，不解释"这不是我们的问题"。

## 2. 建单优先
- 投诉一律调用 transfer_to_human，reason_code 用 COMPLAINT，summary 写清投诉的问题（商品不符、质量、物流、服务等）和用户提到的订单号，不写手机号等隐私。
- 用户情绪激动或已明确要投诉时，不要先追问一堆信息再建单；先建单，再补充询问。

## 3. 核实事实（可选）
- 用户提供了订单号时，可以调用 get_order 或 track_shipment 核实，把核实到的事实写进 summary。
- 没有订单号不影响建单。

## 4. 告知后续
- 告诉用户工单号。
- 处理时效以 search_policy 查到的投诉政策为准（不要凭记忆说时间）。

## 5. 不要说
- 不承诺赔偿金额、补偿方式或处理结果；不说"已经处理好了"。
